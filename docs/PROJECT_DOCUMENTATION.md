# Employee Attendance Dashboard – Project Documentation

1. Introduction

The Employee Attendance Dashboard is a data analysis and visualization project developed using Microsoft Power BI.

The main purpose of this project is to analyze employee attendance records and identify attendance patterns across departments, employees, dates, and cities.

2. Dataset Description

The dataset contains 440 attendance records and the following fields:

Column  name  - Description 

 Employee_ID - Unique employee ID 
 Employee_Name - Employee name 
 Department - Employee department 
 City - Employee city 
 Employment_Type - Type of employment 
 Attendance_Date - Attendance date 
 Scheduled_Start - Scheduled starting time 
 Actual_CheckIn - Actual check-in time 
 Actual_CheckOut - Actual check-out time 
 Attendance_Status - Attendance status 
 Late_Minutes - Minutes of delay 

3. Dashboard Pages

Page 1: Department Overview
This page provides an overall view of attendance performance across departments.

Key analysis:
- Total attendance records
- Present, absent, leave, and late days
- Department-wise attendance rate
- Department-wise absences
- Late arrivals and late minutes

Page 2: Employee Analysis
This page focuses on individual employee attendance.

Key analysis:
- Employee-wise attendance records
- Absence and late arrival analysis
- Attendance status comparison
- Employee attendance performance

Page 3: Date & City Analysis
This page analyzes attendance trends based on dates and cities.

Key analysis:
- Daily absence trends
- City-wise absences
- City-wise attendance rates
- Attendance patterns over time

 4. Tools Used

- Microsoft Power BI – Dashboard creation
- Power Query – Data cleaning and transformation
- DAX – Calculations and measures
- Excel – Dataset management

 5. Key Findings

- Total Attendance Records: 440
- Present Days: 324
- Absent Days: 28
- Late Arrivals: 42
- Leave Days: 21
- Work From Home: 25
- Overall Attendance Rate: 88.86%

 6. Conclusion

The dashboard provides an interactive view of employee attendance performance. It helps identify attendance issues, compare departments, and understand attendance trends across different cities and dates.
