Employee Attendance Dashboard – Power BI

Project Overview:
The Employee Attendance Dashboard is an interactive data visualization project developed using Microsoft Power BI. It helps analyze employee attendance, absences, leaves, late arrivals, and attendance performance across departments and cities.

Project Objectives:
- Analyze total employee attendance records.
- Track present, absent, leave, and late days.
- Compare attendance rates across departments.
- Identify employees with attendance issues.
- Analyze attendance trends by date and city.
- Help management understand workforce attendance patterns.

Dashboard Pages:

1. Department Overview
- Total attendance records
- Present, absent, leave, and late days
- Department-wise attendance rate
- Department-wise absences
- Late arrivals and late minutes

2. Employee Analysis
- Employee-wise attendance details
- Employee absences and late arrivals
- Attendance status analysis
- Employee performance comparison

3. Date & City Analysis
- Daily absence trends
- City-wise absences
- City-wise attendance rates
- Date and city-based analysis

Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
